# Seguridad

Math Starfighters no usa internet, no tiene cuentas y no recoge datos, así que su superficie de ataque es mínima.

Si encuentras un problema de seguridad, no abras una *issue* pública. Usa **Security → Report a vulnerability** en este repositorio (aviso privado de GitHub).

Para comprobar que tu APK es el oficial, sigue [docs/COMPILAR.md → Verificar la descarga](docs/COMPILAR.md#verificar-la-descarga).
